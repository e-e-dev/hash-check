# hash-check
您可以轻松地在文本和文件之间切换，并选择不同的哈希算法进行计算。工具会实时反馈计算状态，并支持一键复制结果。

算法切换：点击顶部的“SHA-256 / SHA-1 / MD5”标签，可以快速切换哈希算法。切换后，如果已有计算结果，工具会自动重新计算。

双输入模式：您可以直接在文本框中输入内容，或通过“选择文件”按钮上传文件。当同时存在时，工具会优先计算文件的哈希值。

结果操作：计算出的哈希值会显示在下方。您可以点击“复制结果”按钮将其保存到剪贴板，或使用“清空全部”按钮重置所有输入和结果。
